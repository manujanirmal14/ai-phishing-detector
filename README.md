# ai-phishing-detector
AI-based phishing URL detector for IE3092
## Features
- Detects suspicious IP-based URLs
- Detects '@' symbol tricks in URLs
- Detects suspicious keywords in domain names (login, secure, verify, etc.)
- Random Forest ML model with 90.9% accuracy on test data

## How to Run
1. Open `Untitled1.ipynb` in Google Colab
2. Upload `phishing.csv` to the Colab session
3. Run all cells
4. Use the URL input box at the bottom to test any link
